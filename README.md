# Gill Gas and Electrical

Static site for Gill Gas and Electrical Ltd, Bedford. Built with Astro.

```bash
npm install
npm run dev
npm run build
```

The production URL in `astro.config.mjs` is `https://gillgasandelectrical.co.uk`. Change `site` in that file if the domain is different before you deploy. The sitemap and canonical links use it.

Company facts are in `src/data/`. Hours, the Google rating and the review text were checked on 15 October 2026. Gas Safe and NAPIT numbers are not printed, because they were not on the public pages checked. Ask the engineer for the ID cards before a job.
